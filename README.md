# 旅行计划超级智能体

## 项目介绍
基于⁠Spring AI+RAG+Tool Calling+MCP 等实现用于提供旅行规划服务的AI 智能体。支持多轮对
话、RAG 知识库检索和MCP 服务调用等能力，并且基于 ReAct 模式，能够自主思考并调用工具来
完成复杂任务，如利用高德地图服务和 PDF 生成工具制定旅行计划。
 主要工作：通过 Spring AI 的对话特性实现对话上下文记忆功能，使 AI 能在多轮对话中保持语境连
贯；利用RAG 查询增强，运用多查询扩展、查询重写和上下文查询增强机制，优化用户原始
Prompt，提升知识检索的召回率和 AI 回复的准确度；利用工具调用和MCP 为智能体扩展了多种功
能，包括天气预报、网络搜索、周边检索、路径规划和PDF 生成等。
